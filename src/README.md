# src

Core Python package code.

Implemented modules now include:

- `phase_id_xcorr/intake`: G0 data intake validation.
- `phase_id_xcorr/preprocessing`: image loading, masking, normalization.
- `phase_id_xcorr/similarity`: NCC scoring primitives.
- `phase_id_xcorr/features`: KikuchiPy Hough/Radon feature extraction.
- `phase_id_xcorr/evaluation`: curated workflows and report generation.
- `phase_id_xcorr/reporting`: run manifest helpers.
- `phase_id_xcorr/ml`: ML dataset preparation, model training, and benchmark-suite orchestration.
