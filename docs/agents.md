# Documentation Subtree Guidance

See the canonical repository policy at `AGENTS.md` in the repository root.

Additional rules for `docs/`:

- `docs/site/` is the canonical user-facing documentation source.
- Workflow, GUI, config, artifact, and scientifically material behavior changes must update the relevant Sphinx pages in the same change.
- Prefer version-controlled SVG and Mermaid sources for documentation figures.
- Keep notation and citations synchronized where algorithm meaning or convention choice is documented.
