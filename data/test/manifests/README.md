# Manifest Templates for Students

Use the JSON example files in this folder as the primary templates:

- `curated_cases.example.json`
- `curated_candidates.example.json`
- `scan_bundle.example.json`
- `preprocessing_policy.example.json`

How to use:

1. Duplicate each `*.example.json` file and remove `.example` from the name.
2. Replace example values with real experimental/indexing values.
3. Keep key names unchanged.
4. Keep paths repo-relative.

Legacy CSV/YAML templates are kept for compatibility with early planning notes:

- `curated_cases.csv`
- `curated_pairs.csv`
- `scan_bundle_manifest.csv`
- `preprocessing_policy.yaml`

For canonical rules and acceptance criteria, see:

- `docs/test_data_setup_plan.md`
